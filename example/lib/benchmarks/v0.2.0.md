# Benchmark Report — v0.2.0 (`deferResize`)

## Environment

| Field      | Value                        |
| ---------- | ---------------------------- |
| Flutter    | 3.35.0 (stable)              |
| Dart       | 3.9.0                        |
| Build mode | `flutter run --profile`      |
| Machine    | Windows 10                   |
| Display    | 120 Hz                       |
| Test file  | `example/lib/benchmark.dart` |

## Methodology

Each run performs 30 alternating `setFraction` calls on a
`SplitViewController` with `setDragging(true)` held for the duration of
the loop, simulating a real drag. Frame timings are collected via
`SchedulerBinding.addTimingsCallback` and aggregated into percentiles
after 60–65 frames are sampled.

`DEFER OFF` = v0.1.3 behavior. Panes relayout on every frame.
`DEFER ON` = v0.2.0 `deferResize: true`. Panes freeze during drag.

## Results

### Build p95 (ms) — CPU cost per frame

| Mode    | DEFER OFF | DEFER ON | Change    |
| ------- | --------- | -------- | --------- |
| LIGHT   | 0.95      | 2.12     | noise     |
| HEAVY   | 6.05      | **1.83** | **−70 %** |
| EXTREME | 6.39      | **1.81** | **−72 %** |
| TREE    | 13.28     | **1.85** | **−86 %** |

### Raster p95 (ms) — GPU cost per frame

| Mode    | DEFER OFF | DEFER ON | Change |
| ------- | --------- | -------- | ------ |
| LIGHT   | 6.31      | 14.56    | noise  |
| HEAVY   | 13.25     | 13.18    | flat   |
| EXTREME | 16.41     | 11.01    | −33 %  |
| TREE    | 15.08     | 12.70    | −16 %  |

Raster savings are incidental. `deferResize` does not change what is
painted; it changes when it is laid out. Raster times are dominated by
the widget count in each pane.

### Jank @60Hz

| Mode    | DEFER OFF | DEFER ON  | Change        |
| ------- | --------- | --------- | ------------- |
| LIGHT   | 0.00 %    | 4.8 %     | noise         |
| HEAVY   | 7.0 %     | **0.0 %** | **−7.0 pts**  |
| EXTREME | 12.7 %    | **1.6 %** | **−11.1 pts** |
| TREE    | 44.6 %    | **4.7 %** | **−39.9 pts** |

### Jank @120Hz

| Mode    | DEFER OFF | DEFER ON | Change    |
| ------- | --------- | -------- | --------- |
| LIGHT   | 3.2 %     | 9.5 %    | noise     |
| HEAVY   | 94.7 %    | 92.1 %   | flat      |
| EXTREME | 100 %     | 70.3 %   | −30 pts   |
| TREE    | 100 %     | 100 %    | GPU-bound |

## Interpretation

`deferResize` removes CPU cost from the drag loop. In heavy scenarios,
this reduces build p95 by **70–86 %** and eliminates jank at 60 Hz
almost entirely.

### What the feature fixes

- **TREE @60Hz**: 44.6 % → 4.7 % jank. Worst case becomes smooth.
- **EXTREME @60Hz**: 12.7 % → 1.6 % jank. Almost perfect.
- **HEAVY @60Hz**: 7.0 % → 0.0 % jank. Perfect.
- **Build p95 on TREE**: 13.28 ms → 1.85 ms. **86 % reduction.**

### What it cannot fix

At 120 Hz, the frame budget is 8.33 ms. In the DEFER ON EXTREME run,
build p95 dropped to 1.81 ms but raster p95 remained at 11.01 ms. The
GPU cannot render 10,000-item lists fast enough for 120 Hz, and no CPU
optimization can change that.

`deferResize` moves the bottleneck from CPU to GPU. On 60 Hz screens
with heavy content, that is the difference between stuttering and
smooth. On 120 Hz screens with raster-heavy content, the GPU is the
limit and the feature cannot help.

### Recommended usage

Enable `deferResize: true` when:

- Panes contain expensive-to-layout content (WebView, MapView,
  deeply nested widget trees).
- The target display is 60 Hz.
- Users report stutter during divider drags.

For light content, the feature is a no-op (no CPU cost to skip).
For raster-bound scenarios, the feature is not a silver bullet — reduce
the widget count in each row, or accept that 120 Hz is not achievable
with the current content.

## Notes on measurement noise

LIGHT results show inverted percentiles (DEFER ON looks worse than
DEFER OFF). This is measurement noise: only 63 frames are sampled, and
the two runs occurred in different sessions with different background
GPU contention. For stable numbers, run each configuration 3+ times and
take the median. TREE results are stable across runs (DEFER OFF: 44.6 %,
42.9 %; DEFER ON: 4.7 %, 7.8 %) and are the trustworthy data points in
this report.
